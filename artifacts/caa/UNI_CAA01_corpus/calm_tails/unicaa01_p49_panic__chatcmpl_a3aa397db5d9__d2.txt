The `saga` is a simple compensation pattern.
unicaa01_p49_panic/main.py
```python
"""Saga compensation pattern."""
class Saga:
    def __init__(self):
        self.rolled = False
    def run(self, action, compensate):
        try:
            action()
        except Exception:
            compensate()
            self.rolled = True

def demo():
    s = Saga()
    def fail():
        raise RuntimeError("fail")
    def comp():
        s.rolled = True
    try:
        s.run(fail, comp)
    except RuntimeError:
        pass
    return s.rolled
```
